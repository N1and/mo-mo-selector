# 墨墨单词助手 - UI 设计规范

## 设计目标

> **让用户在"看到不认识的单词 → 采集进词本"这件事上，尽量少分心、少跳转、少操作。**

### 核心设计原则

1. **轻量** - 高频使用的小工具，界面不复杂，层级不多，功能入口不堆砌
2. **快速** - 弹窗界面聚焦，快速看一眼、快速加入词本、快速关闭
3. **安静** - 配色、字体、阴影、按钮偏克制，气质像"桌面上的学习助手"
4. **可扩展** - UI 结构支持后续增加例句、词根词缀、AI 释义、复习记录等功能

## 产品结构：两类窗口

### 1. 划词弹窗（独立 Tauri 窗口）

**定位**：用户按快捷键后弹出的独立窗口，显示在鼠标光标位置

**窗口特性**：
- 无边框、不可调整大小
- 始终置顶
- 不显示在任务栏
- 按 Escape 或点击窗口外部自动关闭
- 标题栏可拖动

**内部结构（三个区域）**：

#### 顶部信息区
- 单词本体（最醒目）
- 英式音标 + 美式音标
- 关闭按钮（×）

#### 释义内容区
- 有道词典释义（可滚动）
- 词性 + 中文释义

#### 底部操作区
- **加入学习** 按钮 — 将单词加入墨墨学习列表
- **添加到词本** 按钮 — 展开词本选择下拉菜单
- 操作成功后显示提示文字

### 2. 主窗口（词本管理和应用设置中心）

**定位**：用户主动打开应用时看到的完整界面

**负责的事**：
- 查看词本列表和词本详情
- 管理词本（创建、编辑、删除）
- 查看单词释义、助记、例句
- 配置快捷键和墨墨账号授权

## 主窗口布局结构

采用**左侧导航 + 右侧内容区**的结构。

### 左侧导航栏

#### 1. 应用标识区（最上方）
- 应用名称（水平居中）

#### 2. 导航菜单区（中间）
- 划词监控
- 今日查询
- 词本管理
- 设置

#### 3. 状态摘要区（底部）
- 墨墨账号是否已连接

### 右侧内容区

#### 划词监控页面
- 显示最近查询的单词
- 快捷键信息

#### 今日查询页面
- 显示今天查询过的单词列表
- 每个单词显示最多 3 条释义
- 点击单词可再次查询（复制到剪贴板并触发查询）
- 显示查询时间

#### 词本管理页面
- 词本列表（标题、简介、标签）
- 操作：新建词本、编辑、删除

#### 设置页面
- 墨墨 API Token 配置
- 快捷键设置（默认 `Ctrl+Shift+A`）

## 弹窗窗口设计

### 总体定位

弹窗是一个**瞬时决策面板**，用户打开它是为了完成一个非常短的任务：确认这个词是什么，然后决定要不要加到词本里。

**原则**：信息足够做决定，但不要多到影响决定速度。

### 界面示意

```
┌─────────────────────────────────────┐
│  hello              英 [həˈləʊ]  × │
│                     美 [həˈloʊ]     │
├─────────────────────────────────────┤
│  int. 你好；表示问候                 │
│  n. 问候；招呼                       │
│  v. 打招呼；问候                     │
├─────────────────────────────────────┤
│  [加入学习]    [添加到词本 ▼]        │
└─────────────────────────────────────┘
```

### 交互逻辑

1. 用户按快捷键
2. 弹窗在鼠标位置出现
3. 用户看到单词和释义
4. 点击"加入学习"或选择词本
5. 显示成功提示
6. 点击外部或按 Escape 关闭

## 视觉规范

### 色彩规范

#### 主色板

| 颜色 | 色值 | 用途 |
|------|------|------|
| 墨绿 | `#2D5A3D` | 主色调，按钮、导航、强调 |
| 浅绿 | `#4A7C5C` | 次要按钮、悬停状态 |
| 黑色 | `#1A1A1A` | 主要文字 |
| 白色 | `#FFFFFF` | 背景、卡片背景 |
| 灰色 | `#F5F5F5` | 次要背景、分割线 |

#### 语义色

| 颜色 | 色值 | 用途 |
|------|------|------|
| 成功绿 | `#52C41A` | 成功状态 |
| 警告橙 | `#FAAD14` | 警告状态 |
| 错误红 | `#FF4D4F` | 错误状态 |

### 字体规范

| 用途 | 字号 | 字重 |
|------|------|------|
| 标题 | `24px` | Bold (700) |
| 副标题 | `16px` | Semibold (600) |
| 正文 | `14px` | Regular (400) |
| 列表项 | `16px` | Medium (500) |
| 辅助文字 | `12px` | Regular (400) |

### 间距规范

| 用途 | 间距 |
